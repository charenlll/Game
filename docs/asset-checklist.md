# 素材规格与内容清单

适用版本：Phase 1 手机横屏全屏原型。背景铺满整屏，手牌直接覆盖背景。本文只列内容、用途、尺寸、数量与交付格式，不含生成描述词。

## 当前交付方式

原型使用 CSS 场景、占位图形和 SVG 类型图标，无需额外准备美术或音频即可运行。
下列规格用于后续替换规划，不表示现在需要制作全部正式素材。正式素材生产仍按项目总计划在后续阶段安排。
推荐先准备背景、绯川立绘、测试亡魂三项，确认画面占位比例后再准备卡图。
当前尚未建立外部素材自动导入；提供文件后需要一次对应界面接入。

合计：10项图像交付，其中头像可以从立绘衍生。12张起始牌对应6种牌面，重复卡牌不需要重复插图。
卡图只交付插图，不要将名称、费用、效果文字、卡框合并进图片。当前卡图区域较小，以实际浏览器缩小显示效果为准。

横屏版补充：背景不要包含人物、UI文字、卡牌或底部面板；底部约30%仍需完整画出场景，手牌会覆盖其上。中央留给亡魂，左下留给绯川。绯川立绘朝向画面中央（偏右）。正式卡牌插图使用768×1024，透明卡框使用600×900，两者分开交付。

## 通用交付约定

- 使用sRGB；透明图需要真实Alpha通道，不将棋盘格作为背景绘入。
- 提供原始可编辑文件（如有）和导出文件；运行时文件用英文小写与连字符命名。
- PNG素材保留原始版本；上线版本可另压缩。背景目标不超过1MB，单张卡图目标不超过150KB；以画质验收为准。
- 图内不包含UI文字；费用、名称、说明由程序排版，以便数值调整和后续本地化。
- 字体暂用系统字体，无需采购；如后续自带字体，提供可网页分发的字体文件与授权记录。
- 收集作者、来源、授权范围及购买凭证，随素材存档。
