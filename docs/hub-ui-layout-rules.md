# 驿站 UI 适配与层级规则

当前驿站主界面、信物录、渡魂章节选择、摆渡人页面及其弹窗以 **1600×800** 为唯一 UI 设计基准。新增定位和尺寸先在该画布上确定，再由共享 viewport 等比缩放；不得按设备宽高分别拉伸 UI。

## 坐标与缩放

- UI 缩放系数为 `min(viewportWidth / 1600, viewportHeight / 800)`；安全画布按实际视口居中。1600×900 是战斗系统的历史 GameStage 坐标，不能叠加到驿站缩放。
- 驿站环境背景、顶部与底部近景使用独立的 **2560×1440 美术坐标**，由 `src/ui/hub-environment.ts` 按 cover 策略绘制到实际视口。环境素材可以裁掉边缘，但不能出现未覆盖的视口边带。
- 人物和收藏架等 UI 对象属于 1600×800 安全画布。CHH01 使用原始宽高比；允许人物底部被近景自然遮挡，不允许横向或纵向独立拉伸。人物目前是静态 PNG，试验视频不属于运行时资源。
- 每个弹窗的暗色遮罩覆盖**整个实际视口**；弹窗内容固定在同一 1600×800 安全画布上。打开弹窗不应使背景画布跳位。

## 层级与交互

环境背景和灯光在后，人物环境光位于人物后方，人物与收藏架按当前页面层级绘制，底部近景和 UI 在前。地面雾属于独立环境层，不得遮住人物选择入口。新增光效必须保留素材透明通道并支持减少动效设置。

驿站主页的收藏架及小木船仅供展示；进入“信物录”后，小木船才可点击打开详情。人物主视觉的命中区域依图片 Alpha 判断，透明区域不能拦截其他入口。右下角当前摆渡人状态条继续打开角色抽屉。渡魂主按钮使用 `assets/ui/hub/buttons/ferry_primary_button1.png`，不得由旧 HB18 导入映射覆盖。

“牌录”是驿站弹窗，复用渡魂章节条目的 HB19 九宫格底图和对局卡牌组件。顶部按通用牌、已有角色专属牌及浊念切换，卡牌在底图内容安全区横向滑动；未来新增角色卡牌时按归属数据生成分页。图鉴发现记录 `profile.discoveredCardIds` 与本局牌组、养成解锁分开：进入对局的牌组和战斗中实际出现的牌会登记，未发现者显示灰色卡背且不能预览；旧版已完成序章的存档视为已经见过绯川起始牌组。

“渡魂记录”作为亡魂档案展示，不虚构逐局战绩。档案条目由 `src/core/archive/soul-archive.ts` 定义，状态从章节进度和信物存档投影为未遇见、已遇见、已渡魂；序章完成后关联无名孩子与小木船。新章节增加档案定义时，沿用同一进度来源和弹窗布局。

主菜单与驿站共用设置内容及存档中的 `settings`。设置弹窗沿用 HB19 九宫格底图，返回使用对局通用按钮素材；动态内容按统一安全区布局。减少动效为可操作项，同时控制 CSS 动画和驿站环境动画；语言与音量保留禁用按钮形态，等本地化内容和音频播放系统接入后再开放，不得做成表面可调但不生效的控件。

## 多视口验收

以 1600×800 截图为视觉基准，并检查 1600×900、1920×1080、1280×720、1920×1200、2560×1440、2560×1080 和 932×430。`e2e/hub-viewport-audit.spec.ts` 对主界面、设置、牌录、亡魂档案、人物抽屉、信物详情、章节选择、养成页和卡牌详情逐一检查可见范围；`e2e/hub-environment.spec.ts` 检查环境填充与层级。新增弹窗或入口应加入相同矩阵。重点验收文字留在底框安全区、按钮不被裁切、设置与返回可点击、遮罩完整覆盖，以及图片加载成功。
