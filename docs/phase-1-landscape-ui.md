# Phase 1 横屏界面修改与验收

日期：2026-09-22。属于Phase 1内的界面返工，不进入Phase 2。

## 已确认的设计

手机横屏为主，整屏固定，不允许对局页面上下滚动。
背景贯穿整个画面，底部手牌以透明图层叠在场景上，而非放在背景下方的独立容器。
亡魂位于水平中央，角色放在左侧下方。灯火、牌堆、结束回合以悬浮控件贴近屏幕底边。
点选卡牌向上抬起放大，再点击出牌；不会在点选时自动消耗卡牌。再次点选收回。
竖屏显示横屏提示，不重置对局；旋转回横屏继续原局。

## 本次变更

- 新增src/ui/game-view.ts，替换旧网页布局与交互。
- 新增src/game.css：100dvh、禁止页面滚动、横屏尺寸适配、安全区、手牌扇形叠放、选择放大、弹层。
- 新增src/ui/scene.ts：场景、绯川和亡魂的独立SVG占位图层，等待正式素材替换。
- 删除旧src/ui/battle-view.ts与src/style.css，更新入口引用与viewport-fit。
- 移除网页式页头、页脚、固定底部色块、常驻说明文字和操作记录侧栏。
- 菜单、说明、牌组和手记改为覆盖弹层；较长手记只在弹层内部滚动，不滚动对局页面。
- 超过5张手牌时每页5张，通过底部箭头查看其余牌，牌库及手牌规则不变。
- 修复弃牌多选时，已选卡牌覆盖下一张费用点击区的问题：弃牌选择保留原叠放顺序，仅小幅上移和描边。
- 素材清单同步为手机横屏规格：背景2560×1440、角色与亡魂1024×1536、卡图768×1024、卡框600×900。

## 验证结果

TypeScript与Vite构建通过，19项规则测试全部通过。
使用本机Edge、触屏模拟完成8项浏览器测试，全部通过：

1. 背景铺到视口底部，手牌图层透明且层级高于背景；页面没有纵横滚动。
2. 点选抬起放大但不改变灯火与执念，再点收回，确认才结算。
3. 触屏出牌至渡魂成功，并重新开始。
4. 第10回合结束才失败，相同牌序重试保持一致。
5. 弃牌选择、取消、确认均可操作。
6. 抽牌后超过5张手牌，可翻页选择第6张。
7. 568×320、667×375、844×390、932×430、1024×768、1440×900：无页面溢出，亡魂居中、人物偏左下，逐张点选后卡牌仍在视口内。
8. 竖屏提示和横屏恢复，回合状态保持。

已查看手机横屏、选牌放大和桌面实际截图，调整了提示文字位置，避免覆盖角色。
