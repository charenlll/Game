# 夜渡 · Phase 1 浏览器原型

暂用名称：夜渡。中国古风幻想卡牌渡魂玩法测试。当前采用手机横屏优先的全屏牌桌；竖屏显示方向提示，对局不重置。

## 运行

电脑需有 Node.js 22.12+ 或兼容的新版本，本机已验证 Node.js 24.15.0。

```powershell
cd F:\Game
npm.cmd install
npm.cmd run dev -- --port 5173
```

在浏览器打开 http://127.0.0.1:5173 。依赖安装完成后，可双击项目根目录的 `start-game.cmd` 启动。
保留启动窗口；关闭窗口会停止服务。如端口占用，以命令输出的实际地址为准。
本地服务仅监听本机，不是公网发布。

## 玩法

- 每回合3灯火、抽至5手牌；10回合内将执念从30降到0。
- 按住底部手牌，向上拖入中央战斗区并松手出牌；拖回手牌区或取消手势不会消耗灯火。
- 手牌直接叠在完整场景背景上，没有独立底板；对局页面不可上下滚动。超过5张手牌时使用底部箭头翻页。
- 结束回合弃置剩余手牌、恢复灯火并重新抽牌。
- 牌库用尽后将弃牌洗回。正在结算的卡不会被自己的抽牌效果抽回。
- 「整理行囊」需选择两张其他手牌，再确认。取消不会消耗资源。
- 第10回合依然可以成功；结束该回合仍有执念则本场未完成。
- 结束回合按钮位于底部中央。右上角菜单中的「重试相同牌序」复现起始牌序；「重新开始」生成新牌序。

卡牌显示测试场景：`http://127.0.0.1:5173/?card-test`。素材源文件更新后运行 `npm.cmd run assets:import`，脚本只按明确文件名复制并进行字节校验，不分析图片内容。
- 可通过 `http://127.0.0.1:5173/?seed=42` 分享可复现的测试牌序。

仅含单场对局。狐契、生意经、临时牌、专属牌、夜巡路线、局外养成与永久存档尚未实现；刷新会重开。

## 起始牌组

| 牌名 | 数量 | 费用 | 效果 |
|---|---:|---:|---|
| 温言 | 4 | 1 | 执念-4 |
| 静听 | 2 | 2 | 执念-7 |
| 添灯 | 2 | 0 | 本回合灯火+1 |
| 观微 | 2 | 1 | 抽2张 |
| 整理行囊 | 1 | 0 | 选择弃2张其他牌，再抽2张 |
| 旧事 | 1 | 1 | 执念-3，抽1张 |

数值为流程验证用，不是正式平衡。内容在 `src/data` 中定义。

## 验证

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run test:browser
```

浏览器测试默认使用本机 Edge；也可设置 `PLAYWRIGHT_CHANNEL=chrome` 使用 Chrome。
生产构建输出至 `build/`，可运行 `npm.cmd run preview` 预览。为规避本机删除后重建目录的权限错误，构建不自动清空输出目录；发布时使用当次 `index.html` 及其引用文件。
